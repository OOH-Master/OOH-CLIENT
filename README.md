# OOH Mobile

Flutter aplikacija za Out-of-Home (OOH) advertising platformu.

## Quick Start

```bash
flutter pub get
flutter gen-l10n
flutter run -d chrome
```

## Struktura

```
lib/
├── app/          # App, DI, Router
├── core/         # Theme, l10n, widgets
└── features/     # Auth, Discover, Landing...
```
